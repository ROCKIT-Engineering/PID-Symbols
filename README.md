# PID-Symbols

KiCad symbol library for piping and instrumentation diagrams (P&IDs).

This library was created by [ICLR](https://www.imperialrocketry.com/) (Imperial College London Rocketry).

Symbols are defined in [`PID_symbols.kicad_sym`](PID_symbols.kicad_sym) (KiCad 10). In KiCad, add that file under **Preferences → Manage Symbol Libraries**, then place a symbol with **Place → Add Symbol**.

## Symbols

40 symbols. **Symbol** is the name in the library. **Reference** is the default reference designator drawn on the sheet.
